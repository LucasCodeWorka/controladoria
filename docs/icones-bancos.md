# Ícones dos bancos — Fluxo de Caixa

Os símbolos usados na tabela Saldos Bancários ficam em `public/bancos`.
São arquivos locais: a tela não consulta os sites dos bancos para exibi-los.
Todos ocupam uma área de 24 × 24 px, com a proporção original preservada.
Bancos sem logotipo cadastrado ou com erro de carregamento usam o selo com iniciais.

Fontes dos arquivos baixados:

| Banco | Arquivo | Origem |
|---|---|---|
| Itaú | `itau.png` | https://ww117.itau.com.br/staticl/img/itau_logo.png (referenciado por https://ww118.itau.com.br/) |
| Santander | `santander.png` | https://www.santander.com.br/favicon.ico |
| Banco do Brasil | `banco-do-brasil.png` | https://www.bb.com.br/site/wp-content/themes/portal40/img/icn-am.ico |
| ABC Brasil | `abc-brasil.svg` | https://www.abcbrasil.com.br/index_files/logo-abc-ocre.svg |
| Banco do Nordeste | `banco-do-nordeste.svg` | https://www.bnb.gov.br/o/bnb-dxp-theme/images/favicon/favicon.svg |
| Safra | `safra.png` | https://www.safra.com.br/lumis-theme/br/com/bancosafra/safranet/theme/safranet/assets/img/fav/apple-touch-icon-180x180.png |

Os arquivos ICO foram convertidos para PNG. A imagem do Itaú foi reduzida
para 96 × 96 px para evitar carregar o arquivo original de alta resolução.
As marcas pertencem às respectivas instituições e são usadas para identificar as contas.
